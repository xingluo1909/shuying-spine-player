## 📖 简介
  这是集**播放、格式转换、合并、超分**等等功能于一体的跨平台**非官方**spine播放器项目，支持MacOS（仅D-01-release）及Windows（未来仅支持），目前已基本实现2.1到3.8到4.2的播放与转换，因为基本功能大多完善，项目正处于缓慢迭代完善阶段。
## ✨ 后续计划
  目前尚在进行测试的模块:
 - [ ]  1.导出模块：支持PNG / GIF / PNG序列 / MP4，多种分辨率可供选择。
- [ ]   2.桌宠模块：Spine 动画→桌宠，支持点击交互。
 - [ ]  3.更好的超分效果：预计支持多种模型及参数。
 - [ ]  4.增加live2d支持。
 - [ ]  5.增加fbx3D支持。
